## 1. はじめに
このマニュアルは、株式会社Allureの経費処理（経理側の入力・仕訳業務）を、初めて担当する方が一人で完結できるようにまとめたもの。

経費処理で最も大事なのは、書類が「レシート（領収書）」か「請求書」かを最初に見分けること。この2種類で処理ルートが分かれる。新人は「書類を見分ける → 正しいルートで入力する」の2点に集中すればOK。

📌 マニュアルの読み方
- 最初は「2. 全体像」だけ読んで作業の流れをつかむ
- 実際の作業中は「3. 作業手順」を上から順に進める
- 書類の種類で迷ったら「4. レシート vs 請求書の見分け方」を確認
- 困ったら「6. よくあるつまずきポイント」を確認

## 2. 全体像

### 2-1. 経費処理の基本構造
書類の種類によって処理ルートが2つに分かれる。

| 書類 | 支払方法 | 入力ルート | 処理済みマーク |
|---|---|---|---|
| レシート（領収書） | 現金 | ドライブ → 「Allure経費」シート → TKC | ✅ |
| 請求書 | 振込・カード等（現金以外） | ドライブ → TKCへ直接入力 | ⭕️ |

💡 **なぜ分かれているのか**
「Allure経費」シートは現金で動いた取引だけを管理するシート。レシートは現金払いの証拠なのでスプシ経由、請求書は振込・カード等で支払うのでTKCに直接入力。

### 2-2. 作業フロー（5ステップ）

| STEP | 作業内容 | 使うもの |
|---|---|---|
| 1 | ドライブで該当月フォルダを開く | Googleドライブ |
| 2 | 書類を見分ける（レシート or 請求書） | ドライブ内のファイル |
| 3 | レシート → スプシに入力 | 「Allure経費」スプシ |
| 4 | 請求書 → TKCに直接入力 | TKC FX2 |
| 5 | 処理済みマークを付ける | ドライブ＆スプシ |

### 2-3. 締切（月次スケジュール）
📅 **締切のルール**
- 税理士から毎月「○日に報告する」と指定される
- その日までに、該当月のレシート・請求書の入力をすべて完了させる
- 税理士の報告日 = 経理側の入力完了締切
- 前倒しで進めるのが安全。月後半には残件をゼロにできるよう逆算する

## 3. 作業手順（STEP1〜5）

### STEP 1　ドライブで該当月フォルダを開く
Googleドライブの所定フォルダから、処理対象の月フォルダを開く。

**ドライブの構造**
- 月別にフォルダが分かれている（例：2026年4月／2026年5月）
- 担当者が、その月のフォルダにレシート・請求書をアップロード
- ファイル名には店舗名が必ず入っている（FONS／IVY／ICY／NI／Fivent／Allure）

📂 **ファイル名のルール**
ファイル名は担当者の自由形式だが、店舗名は必ず含まれている。ファイル名を見て店舗を判別する。

🔧 **要確認**: ドライブのGoogleドライブ上のフォルダパス／URLは、後日スクショ付きで追記予定。

### STEP 2　書類を見分ける（レシート or 請求書）

| 書類 | 見分け方の特徴 |
|---|---|
| レシート（領収書） | ・店頭で受け取る紙の領収書／レシート<br>・スーパー・コンビニ・薬局・交通機関など<br>・支払い方法は『現金』<br>・宛名なし／簡易な記載が多い |
| 請求書 | ・取引先から発行される正式な請求書<br>・宛名にAllureの社名や店舗名が入っている<br>・支払期日・振込先口座が記載されている<br>・後日、振込・カード等で支払う（現金ではない） |

⚠️ **迷ったときのチェックポイント**
- 支払期日の記載がある → 請求書（後で支払う）
- その場で支払い完了している → レシート（現金）
- 宛名にAllureの社名がある → 請求書の可能性が高い
- どうしても判断できなければ、香織さんまたは税理士さんに確認

### STEP 3　レシート → 「Allure経費」スプシに入力
レシートと判別したものは、「Allure経費」スプレッドシートに1件ずつ入力していく。

📝 **注意**: スプシには複数シートがあるが、入力で使うのは「Allure経費」シートのみ。「soshiji経費」など他のシートには入力しない。

**入力する項目（A〜I列）**

| 列 | 項目 | 入力内容 |
|---|---|---|
| B | 収日（使用日付） | レシートに記載されている日付 |
| C | 支払先 | 店名・取引先名（例：FamilyMart、東急電鉄、マツモトキヨシ） |
| D | 勘定科目 | プルダウンから選択（旅費交通費／消耗品費／通信費／仕入費／広告宣伝費／支払手数料 等） |
| E | 合計金額 | レシート合計金額（税込） |
| F | 使用者 | プルダウンから選択（戸田／NI／IVY／ICY／FONS／Allure） |
| G | リンク | ドライブ上のレシート画像のリンク（領収書（戸田）等） |
| H | TKC | TKC入力完了時にチェックを入れる☑️ |
| I | 備考 | 必要があれば記入（任意） |

💡 **勘定科目に迷ったら**: TKCの過去分を検索。同じ取引先・同じ用途で過去にどの勘定科目を使ったかを確認し、同じ科目で揃える。属人化を防ぎつつ、新人でも判断できる。

#### 3-2. スプシに入力したらTKCへ反映
スプシに入力したレシートは、続いてTKCにも仕訳として登録する。

1. スプシのE列「合計金額」、D列「勘定科目」、F列「使用者（→部門）」を確認
2. TKCで仕訳を作成（借方：勘定科目／貸方：現金）
3. 部門欄でF列「使用者」に応じた店舗（部門）を選択
4. TKC登録完了したら、スプシのH列「TKC」にチェック☑️を入れる

🎯 **戸田社長分の部門**: F列「使用者」が『戸田』のレシートは、TKC入力時に部門『Allure』を選択する。

🔧 **要確認**: TKCの具体的な仕訳入力画面の操作（メニュー位置・部門選択画面・保存手順）はスクショ付きで後日追記予定。

### STEP 4　請求書 → TKCに直接入力
請求書と判別したものは、スプシを経由せず、TKCに直接仕訳として入力する。

**仕訳の基本パターン**

| 支払方法 | 借方 | 貸方 |
|---|---|---|
| 振込（後日） | 該当の勘定科目 | 未払金 |
| 振込（当月） | 該当の勘定科目 | 普通預金 |
| カード払い | 該当の勘定科目 | 未払金 |

**入力時のポイント**
- 勘定科目はTKC過去分を見て、同じ取引先で過去にどう処理したか確認
- 部門欄で該当店舗を選択（FONS／IVY／ICY／NI／Fivent／Allure）
- 消費税区分を選択（食品等は軽減税率8%、それ以外は標準10%）
- 摘要欄に取引先名・内容を簡潔に記入

⚠️ **消費税の使い分け**: 食品（飲食料品）は軽減税率8%。それ以外（消耗品・サービス・新聞代以外）は標準税率10%。請求書に税率の内訳が書かれていることが多いので確認する。

🔧 **要確認**: TKCの請求書入力画面の具体的操作（仕訳パターンの呼び出し方、44列テンプレート使用時の手順など）はスクショ付きで後日追記予定。

### STEP 5　処理済みマークを付ける
入力が終わったら、必ず処理済みマークを付けて未処理と区別する。

| 場所 | マーク | 意味・付ける場所 |
|---|---|---|
| Googleドライブ（レシート） | ✅ | レシートが処理済みであることを示す。付ける位置は自由 |
| Googleドライブ（請求書） | ⭕️ | 請求書が処理済みであることを示す。付ける位置は自由 |
| スプシのH列「TKC」 | ☑️ | TKCに入力反映が完了した行にチェック。レシート分のみ（請求書はスプシ経由しないので不要） |

🚨 **二重マーク忘れに注意**: レシート処理は「ドライブで✅ ＋ スプシのH列でチェック☑️」の2箇所マーキングが必要。片方だけだと処理状況が分からなくなる。

## 4. レシート vs 請求書の見分け方

### 4-1. 判別チェックリスト

| レシート（領収書）の特徴 | 請求書の特徴 |
|---|---|
| ✅ その場で支払い完了している | ⭕️ 後日、振込・カード等で支払う |
| ✅ 支払い方法は『現金』 | ⭕️ 振込先口座の記載がある |
| ✅ 宛名なし／簡易な記載 | ⭕️ 宛名にAllureの社名・店舗名が入る |
| ✅ 支払期日の記載なし | ⭕️ 支払期日が明記されている |
| ✅ 紙のサーマル印字（コンビニ等）も含む | ⭕️ 正式な書面・PDFで発行されることが多い |

### 4-2. よくある具体例

| 取引先・内容 | 書類区分 | 処理ルート |
|---|---|---|
| FamilyMart／セブンイレブンの買い物 | レシート | Allure経費シートへ |
| 東急電鉄／東京地下鉄の交通費 | レシート | Allure経費シートへ |
| マツモトキヨシ／スギ薬局の消耗品 | レシート | Allure経費シートへ |
| ASKULの事務用品（請求書払い） | 請求書 | TKCへ直接 |
| ファイブ表参道の仕入（後日振込） | 請求書 | TKCへ直接 |
| サンレンタオルのレンタル代（請求書払い） | 請求書 | TKCへ直接 |
| プリントパックの印刷代 | 請求書 | TKCへ直接 |

💡 **過去事例で迷いを減らす**: 見分けに迷ったら、過去のスプシ・TKCで同じ取引先がどう処理されているか検索する。同じ取引先は基本的に同じルートで処理しているはず。

## 5. ルールまとめ・参考情報

### 5-1. 勘定科目の主な選択肢
「Allure経費」シートで使われている勘定科目（実例ベース）

| 勘定科目 | 使用例 |
|---|---|
| 旅費交通費 | 電車代・バス代・交通系ICチャージ（東急電鉄／JR／東京地下鉄／パスモ等） |
| 消耗品費 | 薬局・コンビニでの細かい備品（マツモトキヨシ／スギ薬局／FamilyMart／セリア等） |
| 通信費 | 電話・通信関連（アクセスオンライン等） |
| 仕入費 | サロン用品・備品・タオル等（ULTOWA office／ファイブ表参道／サンレンタオル等） |
| 広告宣伝費 | 印刷物・販促物（プリントパック／吉野萌恵／安斎瑠花等のモデル謝礼） |
| 支払手数料 | 振込手数料・印刷手数料等 |
| グリーン関連等 | ASKULの事務用品（カテゴリ別にプルダウンあり） |

💡 **判断のコツ**: 迷ったらTKC過去分を検索→同じ取引先・同じ用途で過去にどの勘定科目を使ったか確認し、同じ科目で揃える。これが最も確実な方法。

### 5-2. 部門（店舗）の選択肢
Allure（アリュール）／ FONS（フォンズ）／ IVY（アイビー）／ ICY（アイシー）／ NI（エヌアイ）／ Fivent（フィベント）

🎯 **戸田社長分は『Allure』**: F列「使用者」が『戸田』のレシートは、TKC入力時に部門『Allure』を選択する。

### 5-3. 消費税の使い分け

| 税率 | 対象 | 具体例 |
|---|---|---|
| 軽減税率 8% | 飲食料品 | コンビニ・スーパーで買った食品・飲料（テイクアウト） |
| 標準税率 10% | 上記以外すべて | 消耗品／交通費／サービス／仕入／広告等 |

⚠️ **混在レシート**: コンビニで食品と日用品を一緒に買ったレシートは、税率が混在する。レシートに税率別小計が書かれているので、それぞれ別仕訳で計上する。

## 6. よくあるつまずきポイント

**Q1. レシートか請求書か判断できない**
→ 「4. レシート vs 請求書の見分け方」のチェックリストを確認
→ 過去の同じ取引先がどう処理されているか、TKC過去分を検索
→ それでも迷えば先輩経理に確認

**Q2. 勘定科目が分からない**
→ TKC過去分で同じ取引先・同じ用途の仕訳を検索→同じ科目で揃える
→ これが最も確実で、属人化を防ぐ方法

**Q3. ファイル名から店舗が判断できない**
→ 担当者がアップする時、ファイル名に店舗名を入れる運用
→ どうしても見つからない場合、レシート画像自体に店舗判別の手がかりがないか確認
→ 不明なら担当者に直接確認

**Q4. スプシのどのシートに入力すればいい？**
→ 必ず「Allure経費」シートのみに入力する
→ 「soshiji経費」など他のシートは触らない

**Q5. 戸田社長のレシートはどう処理する？**
→ 経費は他スタッフと同じ流れで処理OK（給与計算とは別ルール）
→ スプシF列「使用者」に『戸田』を選択して入力
→ TKC入力時の部門は『Allure』を選択

**Q6. 消費税8%か10%か分からない**
→ レシートに税率別の小計が記載されていることが多いので確認
→ 食品・飲料は8%、それ以外は10%が基本
→ コンビニで食品＋日用品の混在は、それぞれ別仕訳に分けて計上

**Q7. 月内に処理が終わらなさそう**
→ 税理士からの報告日が締切。逆算して計画的に進める
→ 月後半に集中しすぎないよう、毎週ルーチンで処理を進める
→ 残件が多くて間に合わない場合は、早めに先輩経理に相談

## 自動化との対応関係（メモ）

このマニュアルが描くAS-IS業務と、Phase 1 仕訳自動化のTO-BE設計（`docs/superpowers/specs/2026-05-01-allure-rescue-design.md`）の対応：

| AS-IS（このマニュアル） | TO-BE（Phase 1） |
|---|---|
| STEP 2 書類判別（人が目視） | OCR後の自動判別（レシート vs 請求書） |
| STEP 3 レシート1件ずつスプシ入力 | C1 領収書OCR → 入出金経費管理シートに一括追加 |
| STEP 3-2 TKC仕訳1件ずつ作成 | C4 TKC FX2 CSVエクスポータで一括取込 |
| STEP 4 請求書1件ずつTKC入力 | C3 仕入請求書OCR → 仕訳CSV化 |
| 勘定科目の手動判断 | C2 大型支払LLM分類＋過去事例参照 |
| 部門の手動選択 | OCRメタデータ＋ファイル名ルールから自動付与 |

「経理は一括取込が主」の原則（メモリー: `feedback_bulk_first_input.md`）に従い、TO-BE では月初の一括取込が主動線、1件ずつ補正は副動線とする。
